# 12 道自测题（W1 语法验收）

**规则：不看任何资料、不用 AI、不搜索。写完再对答案。**

**通过标准：≥10 题正确。**

建议做法：每题一个 `.py` 文件，命名 `ex01_变量.py`、`ex02_列表.py`……
写完一次，全部删掉，**第二天闭卷再写一遍**——第二遍的成绩才是真实水平。

---

## 题 1 · 变量与输入输出

用 `input()` 读入姓名和年龄，输出：

```
你好，张三，明年你 19 岁
```

> 提示：`input()` 拿到的一定是字符串，数字要 `int()` 转换。

---

## 题 2 · 列表统计

给定：

```python
scores = [88, 92, 75, 60, 95]
```

输出平均分（保留 1 位小数）、最高分、最低分。

期望输出类似：

```
平均 82.0，最高 95，最低 60
```

---

## 题 3 · 列表切片

给定 `nums = list(range(1, 21))`（即 1 到 20），输出：

1. 前 5 个
2. 后 5 个
3. 所有偶数
4. 倒序

> 提示：`nums[:5]`、`nums[-5:]`、`nums[::-1]`、`[n for n in nums if n % 2 == 0]`

---

## 题 4 · 字典计数

给定一句话：

```python
text = "风景园林是处理人与自然关系的学科"
```

统计每个字出现的次数，**按次数从高到低**输出前 3 名。

> 提示：`dict.get(ch, 0) + 1`；排序用 `sorted(d.items(), key=lambda x: x[1], reverse=True)`

---

## 题 5 · 字典列表排序

给定：

```python
students = [
    {"name": "小林", "score": 88},
    {"name": "小周", "score": 95},
    {"name": "小陈", "score": 72},
]
```

按分数从高到低排序，输出每行一个「名字: 分数」。

---

## 题 6 · 循环与条件

输出 1–100 中**能被 3 或 5 整除、但不能同时被 3 和 5 整除**的数，并在最后输出一共有多少个。

> 提示：能被 3 整除 `n % 3 == 0`；同时整除就是能被 15 整除。

---

## 题 7 · 函数：质数判断

写一个函数 `is_prime(n)`，判断 n 是否为质数（返回 True/False）。
然后输出 2–50 中的所有质数。

> 提示：从 2 试除到 `int(n ** 0.5) + 1`。

---

## 题 8 · 函数的默认参数

写一个函数：

```python
def greet(name, prefix="你好"):
    ...
```

用两种方式调用它，分别输出：

```
你好，小林
嗨，小林
```

---

## 题 9 · 字符串处理

给定：

```python
url = "https://example.com/course?course=landscape&week=3"
```

提取出 `course` 的值 `landscape` 和 `week` 的值 `3`。

> 两种写法都试试：
> - 用 `split()` 手工切
> - 用 `from urllib.parse import urlparse, parse_qs`

## 题 10 · 文件读写

1. 把 `[88, 92, 75, 60, 95]` 每行一个数字写进 `scores.txt`
2. 再把文件读回来，求和并输出

> 提示：写用 `open("scores.txt", "w", encoding="utf-8")`，读用 `"r"`。
> **`encoding="utf-8"` 一定要写**，Windows 默认是 GBK，会乱码。

## 题 11 · 异常处理

尝试读一个不存在的文件 `nothing.txt`。
要求：**程序不崩溃**，打印一句「文件不存在：nothing.txt」。

> 提示：`try: ... except FileNotFoundError: ...`

## 题 12 · 类

定义一个 `Student` 类：

- 有 `name` 和 `score` 两个属性
- 有方法 `passed()`，分数 ≥ 60 返回 `True`
- 有方法 `describe()`，返回 `"小林 88 分 通过"`

创建 3 个学生对象，打印他们的 `describe()`。

> 这就是本周"看懂就行"的部分。**写不出来不算失败，能看懂别人写的就行。**
