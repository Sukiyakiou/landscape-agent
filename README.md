# landscape-agent

面向设计类专业（风景园林 / 景观设计）的教学智能体。

> 当前状态：**W1 起步阶段**。目前只完成了环境搭建与大模型 API 调用，还没有检索与知识库。

## 这是什么

一个把风景园林课程的专家判断（评图标准、案例逻辑）显式化、并用于教学问答与方案反馈的智能体。
不是通用聊天机器人，它的回答必须能引用课程资料的具体段落。

## 为什么要做

景观设计的评图反馈高度依赖老师个人经验，且滞后、主观、难以复现。
本项目尝试把这种隐性判断拆成可执行的结构（量规 + 教学策略），并验证它是否真的提升了学生的设计分析能力。

## 快速开始

```powershell
# 1. 装 uv（如果还没有）
pip install uv

# 2. 同步依赖（会自动创建 .venv 并安装 Python 3.12）
uv sync

# 3. 配置密钥
copy .env.example .env
# 用记事本打开 .env，填入自己的 API Key

# 4. 运行
uv run python hello_llm.py
```

## 技术选型（当前）

| 用途 | 选择 | 原因 |
|---|---|---|
| 包与环境管理 | **uv** | 比 conda 快一个数量级，且能锁定 Python 版本 |
| 生成模型 | DeepSeek / GLM-4-Flash | 中文强、便宜、有免费额度 |
| 接口协议 | OpenAI 兼容 | 换供应商只改 base_url，代码不动 |

## 局限

- 目前**没有任何专业知识库**，回答完全来自模型本身，会有幻觉。
- 只处理文本，而景观设计的核心信息在图纸里。
